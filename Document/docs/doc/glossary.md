# 中英文术语表

本文约定 3.2 文档使用的中英文术语，帮助区分实验对象、分析步骤与报告内容。命令、参数、字段名和报告中的界面标签保留软件原文。

## 实验对象与标识 {#objects-and-identifiers}

| 中文 | English | 文档中的含义与使用约定 |
| :--- | :--- | :--- |
| 微珠 | bead | 实验中携带条形码的微珠。正文统一使用“微珠”；同一液滴中可能包含多个微珠，微珠数不等于细胞数。 |
| 液滴 | droplet | 微流控形成的反应液滴。液滴可能包含背景、单个细胞或多个细胞，不直接等同于细胞。 |
| 细胞 | cell | 生物学对象。在分析输出中，“识别出的细胞”指通过相应识别规则的条形码或微珠合并集合；具体统计单位以指标定义为准。 |
| 样本条形码 | sample barcode | C6 中用于区分生物学样本的标签。正文首次出现可写“样本条形码（sample barcode）”；界面中的 `Sample Barcode` 保留原样。 |
| 微珠条形码 | bead barcode | 标识微珠的条形码；微珠合并后可对应同一个细胞标识。 |
| 细胞条形码 | cell barcode | 矩阵、BAM 或元数据中的细胞相关标识。保留完整标识及样本后缀；不能仅凭其存在认定为有效细胞。 |
| 重叠群 | contig | 序列组装产物。“全长”用于描述序列或重叠群，不用于修饰克隆型识别。 |
| 克隆型 | clonotype | 按分析规则划分的免疫受体序列类别；克隆型识别与全长序列组装是不同步骤。 |

## 分析步骤与报告 {#analysis-and-reporting}

| 中文 | English | 文档中的含义与使用约定 |
| :--- | :--- | :--- |
| 细胞识别 | cell calling | 根据条形码计数、背景模型或指定规则确定用于后续分析的细胞集合。正文统一用“细胞识别”；方法和阈值以相应模块说明为准。 |
| 样本解复用 | sample demultiplexing | 根据样本条形码将混合数据分配到样本。英文统一拼写为 `demultiplexing`；无法分配的读段单独统计。 |
| 微珠合并 | bead merging | 将判定来自同一细胞或液滴的微珠关联到统一标识；具体方法以模块流程为准。 |
| 联合分析 | joint analysis | 对关联的样本或组学数据进行比较或分析。使用时说明是流程调度、细胞关联，还是下游数据整合。 |
| 流程统一调度 | unified workflow orchestration | 从同一入口配置并执行多个分析模块，不等同于跨组学联合降维或聚类。 |
| 数据整合 | data integration | 下游对多个样本或组学进行联合建模；是否需要批次校正取决于实验设计。 |
| 组合报告 | combined report | 集中展示各模块的指标和图表。生成组合报告本身不表示执行了跨组学联合降维、聚类或批次校正。 |
| 批次汇总报告 | batch summary report | C6 中汇总共享文库指标和样本间比较的报告，与各样本报告区分。 |
