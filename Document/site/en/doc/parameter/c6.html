    C6 Multiplexed Analysis Parameters ¶

    C6 multiplexed single-cell RNA analysis is executed via the dnbc4tools multi run command using a sectioned CSV configuration file that maps shared pooled libraries to Sample Barcodes.

    See the Chinese–English Glossary for terminology.

    Execution Command¶

    dnbc4tools multi run \
  --name c6_demo \
  --csv sample.config.csv \
  --outdir ./results \
  --threads 40

    Basic Options¶

    Option Required Description
    --name Yes Unique identifier for the run. Results are written to <outdir>/<name>/
    --csv Yes Path to the sectioned CSV configuration file
    --outdir No Path to the output directory; defaults to the current directory
    --threads No Number of CPU threads to use [default: all available cores]

    CSV File Structure¶

    A standard C6 configuration file contains three essential sections: [rna] (global RNA and experiment-level settings), [libraries] (paths to input sequencing data), and [samples] (mapping of sample names to Sample Barcodes).

    Minimal Configuration Example ¶

    [rna]
genomeDir,/database/scRNA/Human
chemistry,scRNAC6
darkreaction,auto

[libraries]
fastqs,feature_types
/rawdata/c6_pooled_run,rna

[samples]
sample_id,probe_barcode_ids
S1,BC01
S2,BC02;BC03

    Optional BAM output setting: This example uses the default [rna] no_bam,false, generating per-sample BAMs, unassigned BAM, and oligo BAM with their applicable indexes. To save disk space, add no_bam,true to [rna]; BAM files and their indexes will then be omitted.

    [libraries] Specification¶

    The [libraries] section declares the directories containing input sequencing data and their corresponding modality types.

    Column Required Rules & Description
    fastqs Yes Path to the directory containing paired FASTQ files. For C6 RNA libraries, this directory must contain cDNA/ and oligo/ subdirectories housing the respective FASTQ files.
    feature_types Yes Modality type; fixed to rna for C6 RNA.

    Tip: Sequencing Consistency & Batch Handling All FASTQ inputs in a single run must originate from the same library batch with identical sequencing modes and dark reaction settings; data from different libraries cannot be mixed. If different sequencing batches of the same library batch exhibit differing dark reaction cycles or read lengths, use the FASTQ trimming tool fqsubC4 to trim reads to match the standard library structure (see Library Structure).

    [samples] Specification¶

    The [samples] section declares the unique identity of each biological sample and its assigned Sample Barcodes.

    Column Required Rules & Description
    sample_id Yes Unique identifier for the sample. Must begin with an alphanumeric character and contain only letters, numbers, ., _, and -. Reserved words such as unassigned or non_multiplexed are prohibited.
    probe_barcode_ids Yes Assigned Sample Barcode identifier (e.g., built-in BC01) or custom barcode DNA sequence. If a sample uses multiple barcodes, delimit them with semicolons ; or pipes \| (e.g., BC02;BC03). The same barcode must not be assigned to multiple samples.
    expectcells No Per-sample expected cell count override (positive integer). If omitted, falls back to the [rna] default. Does not accept auto.
    forcecells No Per-sample forced cell count override (positive integer). Takes precedence over expectcells.
    minumi No Per-sample minimum UMI threshold override. Droplets below this count are excluded from called cells.

    Configuration with Per-Sample Parameter Overrides: ¶

    [samples]
sample_id,probe_barcode_ids,expectcells,forcecells,minumi
Sample_A,BC01,3000,,800
Sample_B,BC02;BC03,5000,,1000

    [rna] Experiment-Level Settings ¶

    Parameter Default Description
    genomeDir Required Path to the STAR reference genome index directory
    chemistry scRNAC6 C6 chemistry name, fixed to scRNAC6 (omitted or set to auto normalizes to this name)
    darkreaction auto Dark cycle detection. auto automatically identifies dark reaction cycles across cDNA and Oligo reads
    high_occupancy_filter true When true, applies cross-sample high-occupancy droplet filtering across the pooled experiment to remove multiplet artifacts
    sample_failure_policy skip Sub-sample failure policy: skip logs errors and continues processing remaining samples; fail terminates the run upon any sample failure
    no_bam false When true, skips all BAM generation (sample BAMs, unassigned BAM, and oligo BAM) to conserve disk space and execution time
