# C6 多样本分析参数说明 <a id="c6"></a> {#c6-parameters}

C6 多样本 RNA 分析通过 `dnbc4tools multi run` 入口执行，并通过分段式 CSV 配置文件定义共享文库与样本 Sample Barcode 的对应关系。

术语定义参见[中英文术语表](../glossary.md)。

---

## 运行命令 <a id="运行命令"></a> <a id="_1"></a> {#execution-command}

```bash
dnbc4tools multi run \
  --name c6_demo \
  --csv sample.config.csv \
  --outdir ./results \
  --threads 40
```

### 基础参数 <a id="_2"></a> {#basic-options}

| 参数 | 是否必需 | 说明 |
| :--- | :--- | :--- |
| `--name` | 是 | 任务名称；分析结果将输出至 `<outdir>/<name>/` |
| `--csv` | 是 | C6 分段式 CSV 配置文件路径 |
| `--outdir` | 否 | 结果输出目录，默认为当前目录 |
| `--threads` | 否 | 分析所分配的 CPU 线程数，默认全部可用核心 |

---

## CSV 配置文件结构 <a id="csv-配置结构"></a> <a id="csv"></a> {#csv-file-structure}

C6 配置文件包含三个核心分段：`[rna]`（全局 RNA 与实验级参数）、`[libraries]`（测序文库路径）以及 `[samples]`（样本与 Sample Barcode 对应表）。

### 最小可用配置示例 <a id="_3"></a> {#minimal-configuration}

```csv
[rna]
genomeDir,/database/scRNA/Human
chemistry,scRNAC6
darkreaction,auto

[libraries]
fastqs,feature_types
/rawdata/c6_pooled_run,rna

[samples]
sample_id,probe_barcode_ids
S1,BC01
S2,BC02;BC03
```

> **可选 BAM 输出设置**：本示例保留默认的 `[rna] no_bam,false`，生成逐样本 BAM、未分配 BAM 和 Oligo BAM 及其适用的索引。若需节省存储空间，可在 `[rna]` 中添加 `no_bam,true`；此时不生成 BAM 文件及其索引。

---

## `[libraries]` 文库路径配置 <a id="libraries-配置规范"></a> <a id="libraries"></a> {#libraries-specification}

`[libraries]` 区块声明输入测序数据的目录路径及其模态类型。

| 列名 | 是否必需 | 说明 |
| :--- | :--- | :--- |
| `fastqs` | **是** | 包含配对测序数据的目录路径。对于 C6 RNA 文库，该目录下须包含 `cDNA/` 与 `oligo/` 子目录分别存放对应的 FASTQ 文件。 |
| `feature_types` | **是** | 测序数据模态类型，C6 RNA 固定填写 `rna`。 |

> **提示：测序文件一致性与批次处理**
> 同一分析中的所有测序文件必须来自同一文库批次，测序模式与暗反应设置须保持一致；不同文库的数据不能混合输入。
> 如果同一文库批次的不同测序批次存在暗反应模式或者测序长度不一致的情况，则需要使用 FASTQ 裁剪工具 [`fqsubC4`](tools.md#fastq-切割-fqsubc4) 对 reads 进行裁剪，具体裁剪位置请参考[文库结构识别](../library_structure.md#scrna)。

---

## `[samples]` 样本表配置规范 <a id="samples-配置规范"></a> <a id="samples"></a> {#samples-specification}

`[samples]` 区块用于声明每个生物学样本的唯一标识及所分配的 Sample Barcode。

| 列名 | 是否必需 | 填写规则与说明 |
| :--- | :--- | :--- |
| `sample_id` | **是** | 样本唯一标识。以字母或数字开头，仅允许字母、数字、`.`、`_` 和 `-`；禁止使用 `unassigned` 或 `non_multiplexed` 等系统保留字。 |
| `probe_barcode_ids` | **是** | 分配给该样本的 Sample Barcode ID（如内置 `BC01`）或自定义 DNA 序列。**若同一样本分配了多个条形码，请使用分号 `;` 或竖线 `\|` 连接**（例如 `BC02;BC03`）。禁止将同一个条形码重复分配给不同样本。 |
| `expectcells` | 否 | 样本级预期细胞数覆盖值。填入正整数；留空时自动继承 `[rna]` 中的全局设置。覆盖列不填 `auto`。 |
| `forcecells` | 否 | 样本级强制细胞数覆盖值。填入正整数；优先于 `expectcells`。 |
| `minumi` | 否 | 样本级最低 UMI 阈值覆盖值。低于该 UMI 阈值的液滴不被计为真实细胞。 |

### 包含逐样本参数覆盖的示例： <a id="_4"></a> {#sample-overrides}

```csv
[samples]
sample_id,probe_barcode_ids,expectcells,forcecells,minumi
Sample_A,BC01,3000,,800
Sample_B,BC02;BC03,5000,,1000
```

## `[rna]` 实验级设置 <a id="rna-设置"></a> <a id="rna"></a> {#rna-settings}

| 参数 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `genomeDir` | **必需** | STAR 参考基因组索引目录路径 |
| `chemistry` | `scRNAC6` | C6 试剂类型，固定为 `scRNAC6`（省略或设为 `auto` 会自动归一化为该名称） |
| `darkreaction` | `auto` | 暗反应检测。`auto` 自动检测 cDNA 与 Oligo 的暗反应周期 |
| `high_occupancy_filter` | `true` | 是否在实验全局应用跨样本高占用异常液滴过滤，剔除潜在双胞/多胞噪声 |
| `sample_failure_policy` | `skip` | 子样本运行异常策略：`skip` 记录失败状态并继续完成其余正常样本；`fail` 遇任意样本失败立即终止整个流程 |
| `no_bam` | `false` | 设为 `true` 时跳过所有 BAM 生成（包括逐样本 BAM、未分配 BAM 和 Oligo BAM），减少 BAM 写入所需的存储空间和运行时间 |
